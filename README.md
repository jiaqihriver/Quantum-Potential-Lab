# 势场中的电子 · 半导体量子力学探究实验室

一个**纯交互式**的量子力学探究网页：把电子放进不同的势能函数里，亲手拖动滑块，观察它做出经典物理完全无法解释的行为——从分立能级、禁区渗透、隧穿，一路玩到能带。

内容依据 Donald A. Neamen《Semiconductor Physics and Devices: Basic Principles, 4th ed.》第 2–3 章，公式编号与教材一致。

## 三个必玩的探究任务

1. **量子化的诞生**（实验台①）：把阱宽 a 从 1 nm 慢慢拉到 10 nm，观察能级台阶如何"塌"回去——这正是宏观世界能量看起来连续的原因。
2. **反直觉的反弹**（实验台②）：把 E 调到 **大于** V₀，能量明明够，反射概率却不为零。想想为什么（提示：和光从空气进入玻璃的界面反射类比）。
3. **穿墙术的指数律**（实验台③）：STM 预设下把势垒宽度从 1 nm 加到 2 nm，看隧穿概率掉多少个数量级——这就是 STM 有原子级分辨率的原因。

进阶：实验台④里把 P′ 从 25 拖到 0.4，你会亲眼看到"孤立原子 → 晶体"的能带演化全程。

## 给讲课教师

- 全部物理量（波函数、R/T 系数、能级、能带）由浏览器内置求解器**实时精确计算**：转移矩阵法解定态薛定谔方程，与解析式误差在机器精度（详见 [`VALIDATION.md`](VALIDATION.md)）
- 支持**离线 + 投屏授课**；每个实验台底部有"探究问题"可展开课堂讨论
- 数值细节：能量的单位 eV、长度单位 nm；有效质量可选 m₀ / GaAs 0.067m₀ / Si 0.26m₀（隧穿模块另有 SiO₂ 0.5m₀）
